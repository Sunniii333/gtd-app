# GTD

A local-first Getting Things Done (GTD) task manager. Capture items into an
Inbox, then clarify each one into a Next Action, Project, Waiting For, or
Someday/Maybe item.

Built with React, TypeScript, Vite, Zustand (persisted to `localStorage`),
and Tailwind CSS. No backend — all data stays in your browser.

## Development

```bash
npm install
npm run dev
```

## Deployment

Deployed on [Vercel](https://vercel.com), auto-deploying from the `master`
branch of this repository.
